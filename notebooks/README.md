# Notebooks Folder

This folder contains exploratory analysis notebooks for the Fintech Review Analytics project.

## Files

- `exploratory_analysis.ipynb` - Main analysis notebook (to be created)
- `sentiment_analysis_demo.ipynb` - Sentiment analysis demonstration

## How to run

1. Activate virtual environment: `venv311\Scripts\activate`
2. Launch Jupyter: `jupyter notebook`
3. Open the desired notebook

## Key Analyses Performed

- Data quality assessment
- Sentiment distribution visualization
- Rating pattern analysis
- Review text length analysis
- Sample review extraction
